# Space Agent Handoff Contract

Last verified: 2026-05-06

## Route Shape

Standard route:

Owner -> Gateway -> Pi recommendation -> Agent Zero approval -> Space Agent research -> Gateway -> responsible agent

Gateway may skip Pi when the route is obvious, but Agent Zero remains commander for owner missions.

## When To Use Space Agent

Route to Space Agent when the request needs:

- live web research
- website or page reading
- browser interaction
- YouTube or video inspection
- Firecrawl search, scrape, crawl, map, or extract
- source verification
- screenshot or page-state evidence

Do not route normal chat, coding-only tasks, delivery, email sending, Build-Wiki execution, Drive upload, Zapier writes, HeyGen generation, Brain writes, or SMB/Fork 2 to Space Agent.

## Research Packet Requirements

Space Agent returns:

- job id
- original request
- assigned supervisor
- source list
- findings
- confidence
- evidence snippets
- citations or URLs
- blockers
- recommended next agent

## Responsibility Return

After research, Gateway returns responsibility to:

- Agent Zero for final owner response or operational decision
- Hermes for skill or workflow design
- Pi for route-quality review
- another specialist for non-web work

Space Agent exits the task unless more research is routed back to it.

## Audit

Every handoff must be auditable with:

- source
- target
- requested action
- selected route
- policy result
- status
- blocker or result

Owner-facing output must not expose raw internal task ids.
