Responsive rules

  • ≥1280px (desktop): full canvas, side panels, audit drawer.
  • 768–1279 (tablet): sidebar collapses to icons + labels; canvas becomes a single column with the same data; audit moves to a footer drawer.
  • <768 (mobile): top tally cards → bottom tab bar (Map / Registry / Policies / Audit). Canvas replaced with prioritized list. Bridge approval surfaces as a top-of-feed card with countdown. Node detail is push-navigated, not modal.
  • Notifications: Bridge requests, denied actions, and red-status changes can fire OS-level pushes. Approvals are signed with device-bound key — the phone is itself a Bridge factor.
