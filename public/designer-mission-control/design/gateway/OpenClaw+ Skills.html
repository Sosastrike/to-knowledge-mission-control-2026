Skill discovery contract

Each skill exposes describe() returning {input_schema, output_schema, severity, scopes, cost_estimate}. The Gateway caches the descriptor for 5 minutes and refuses calls whose payload doesn't validate against input_schema. Severity drives Bridge Session enforcement, not the skill itself — a skill cannot "ask nicely" past the gate.
