Routing rules

Owner → Gateway → Agent Zero → opencloud (parent) → child worker. Agent Zero never names a worker directly; it asks the parent to dispatch by capability. The parent's discovery contract (discovery_kind=opencloud_workflow_list) returns the live worker list per request, so retired workers disappear without a code push and new workers light up without hand-wiring.
